# 天下 · 천하 Complete v3

현재설정.txt를 기준으로 만든 GitHub Pages용 단일 웹게임 프로토타입입니다.

## 실행
1. 이 폴더의 `index.html`을 GitHub 저장소 root에 업로드
2. Settings → Pages → Deploy from a branch → main / root
3. 배포된 주소로 접속

## 구현 범위
- 시작 흐름: 시대 / 난이도 / 지역 / 신분 / 가족 / 재능 / 성격 5축 / 능력치 / 삶의 방향
- 8종 능력치와 자유분배
- 7단계 경지, 돌파 조건, 강제 돌파, 경지차 페널티
- 무공 숙련도 배율
- 5시진 하루, 계절, 폐관수련 시간 스킵
- 6권역 물가 / 위협 / 전쟁 / 무역로 차단 기반
- 무기 5등급, 내구도, 장비, 방어구
- 소모품 및 영약 성공/실패
- 노드형 대화, 성격/스탯/평판 조건, 거짓말/협박, 기억
- 빈사/구조/사망/후손 이어하기
- 개인/지역/천하 사건 및 개입
- 천마교/무림맹/경제위기 가중치
- NPC 자동 생성, 지역별 이름 풀, 5축 성격, 등급, 관계, 기억
- 문파 가입/창설, 인원/재정/시설/파벌/외교
- 문파 시설 업그레이드와 재정
- 후계자 승계 알고리즘 및 분쟁/분열
- 인물 도감
- 사건 알림
- localStorage 단일 슬롯, schemaVersion, 구버전 세이브 마이그레이션
- 텍스트 백업 코드
- 초반 튜토리얼 안내
- 오리지널 SVG 무협 실루엣 UI

## 주의
현재설정의 수치는 기준값이며 실제 밸런스 테스트에 따라 조정할 수 있습니다.
특정 상용 작품의 캐릭터/이미지를 복제하지 않고 오리지널 무협 웹툰풍 UI/실루엣으로 구성했습니다.
